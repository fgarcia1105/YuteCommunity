# Decisiones de implementación para E1

Estas decisiones desarrollan los puntos abiertos del Plan de Construcción V1.
No modifican la KB, los ADR aceptados ni el alcance MVP.

## DT-01 — Interfaz Web

Selección técnica: Blade + Livewire.

Motivo:
Concentrar el desarrollo Web en Laravel/PHP para un desarrollador
con disponibilidad aproximada de dos horas semanales.

Límites:
- La Web debe cubrir el alcance responsive completo aprobado.
- Las reglas financieras residen en casos de uso y dominio del backend.
- Livewire y la API para Flutter utilizan esos mismos casos de uso.
- La autorización se verifica en backend y por recurso.
- Esta elección no resuelve autenticación/MFA ni incorpora automáticamente
  las funciones de un starter kit.

Pendiente:
Fijar versiones compatibles y verificar la integración.

Referencia:
https://laravel.com/docs/13.x/starter-kits

## DT-08 — Git y CI/CD

Selección técnica:
GitHub como repositorio y GitHub Actions para integración continua.

Flujo:
- main contiene cambios integrados.
- Cada entrega utiliza una rama corta.
- Los cambios se revisan mediante pull request.
- Las comprobaciones automáticas se incorporan al preparar la aplicación.
- Los secretos no se versionan.

Estado:
Proveedor y flujo seleccionados.
Pipeline pendiente de implementación.
Despliegue pendiente del entorno de destino y DT-12.

Referencia:
https://docs.github.com/en/actions/get-started/understand-github-actions
